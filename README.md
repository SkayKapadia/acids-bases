# Acids & Bases Trainer – Chapter 11

An interactive, step-by-step study guide for Chapter 11 (Acids and bases). It is plain HTML/CSS/JS, so there's nothing to build or install.

## What's inside

- **Learn** – 9 parts in textbook order (11A → 11E) with explanations, interactive visuals and step-by-step worked examples. Each part ends with a checkpoint quiz, and finishing the quiz unlocks the next part.
- **Q&A** – every check-in, section and chapter-review question from the chapter, with worked answers. It's searchable and can be filtered by section.
- **Glossary** – all key terms from the chapter.
- **Final test** – unlocks after all 9 parts. It has about 29 mixed questions drawn from the whole chapter and gives an encouraging topic-by-topic breakdown.
- **Chat helper** (💬 button) – the student types a question from the chapter and gets the answer. It also solves simple strong acid/base pH questions step by step. It runs entirely in the browser, uses no AI service and needs no internet connection.

## Put it on GitHub Pages

1. Create a new GitHub repository (e.g. `acids-bases`).
2. Upload the **contents of this folder** (`index.html`, `styles.css`, `qa.js`, `lessons.js`, `app.js`, `README.md`) to the repository root.
3. In the repo, go to **Settings → Pages**, set **Source: Deploy from a branch**, and choose branch `main` and folder `/ (root)`.
4. After a minute, your link will be `https://<your-username>.github.io/acids-bases/`. Share it with your student.

> Don't upload the textbook PDF. It is copyrighted, and the site doesn't need it.

## Teacher preview

Add `?teacher=1` to the link (e.g. `https://<you>.github.io/acids-bases/?teacher=1`) to unlock every part and the final test without doing the quizzes.

## Notes

- Progress is saved in the student's browser on that device. It doesn't sync between devices.
- To try it locally, open `index.html` in a browser, or run `python3 -m http.server` in this folder and visit `http://localhost:8000`.
